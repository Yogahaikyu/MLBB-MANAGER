# MLBB Manager 2026

Game manager/simulation MOBA berbasis HTML/CSS/JavaScript. Bisa dimainkan langsung di browser dan dipublikasikan menggunakan GitHub Pages.

## Isi game
- Career manager musim 2026
- 13 database liga/region
- Tim MLBB 2026 dari beberapa region: Indonesia, Philippines, Malaysia, Singapore, Myanmar, Cambodia, Thailand, MENA, LATAM, Brazil, North America, EMEA East, EMEA
- Squad dengan EXP/Jungle/Mid/Gold/Roam
- OVR, form, stamina, chemistry, morale, skill
- Training Center
- Tactics
- Transfer market
- Budget, fans, reputation
- 14-week regular season BO3
- Klasemen/simulasi karier dan records
- Save lokal di browser
- Responsive untuk HP dan PC
- Tidak membutuhkan server/database

## Cara menjalankan
Buka `index.html`.

## GitHub Pages
Upload `index.html`, `style.css`, `data.js`, `game.js`, dan `README.md` ke repository. Lalu buka Settings → Pages → Deploy from branch → main → root.

## Sumber data 2026
Database liga/tim disusun berdasarkan pengecekan sumber MLBB esports 2026 yang tersedia pada saat pembuatan:
- Official MPL Indonesia 2026: https://id-mpl.com/
- Official MPL Philippines 2026: https://ph-mpl.com/
- Official MPL Malaysia 2026: https://my.mpl.mobilelegends.com/
- MLBB esports 2026 calendar/background: https://escharts.com/news/mlbb-esports-2026-event-calendar-entire-season

Penting: angka OVR/power, ekonomi, dan sebagian struktur liga non-franchise adalah **abstraksi untuk gameplay**, bukan statistik resmi Moonton. Game tidak menyertakan logo, gambar, suara, atau kode proprietary dari MLBB/SuperKickoff.

## Lisensi
Kode game ini adalah karya baru untuk prototype/game manager. Nama merek, tim, dan liga pihak ketiga tetap menjadi milik pemilik masing-masing.
